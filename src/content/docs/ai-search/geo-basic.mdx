# GEO 기초 (Generative Engine Optimization)

**GEO(Generative Engine Optimization, 생성 엔진 최적화)** 는 ChatGPT·Perplexity·Gemini·Google AI Overviews·Claude 같은 생성형 AI 엔진이 답변을 만들 때 우리 브랜드·콘텐츠가 **인용·추천**되도록 설계하는 마케팅 분야입니다. 용어는 2023년 11월 프린스턴대 연구팀(Aggarwal et al.)의 논문에서 처음 공식화됐습니다.

## GEO가 필요한 이유

- 전통 검색은 '10개의 블루 링크'를 보여주지만, 생성 엔진은 답변당 **2~7개 도메인만 인용**합니다.
- AI 인용 5건 중 4건은 구글 상위 10위 밖의 페이지라는 연구 결과가 반복 확인됩니다. **순위 1위가 AI 답변 노출을 보장하지 않습니다.**
- Gartner는 2026년 전통 검색량 25% 감소를 전망했고, AI Overviews는 월 20억 사용자를 넘겼습니다.
- 국내도 네이버 AI 브리핑(월 3,000만 명)·AI 탭과 ChatGPT 한국 앱 MAU 2,345만 명이 병행하는 '두 표면' 시장입니다.

## GEO 작동 원리

현행 생성형 검색 엔진 대부분은 **RAG(Retrieval-Augmented Generation)** 기반입니다.

1. 사용자 질문 → 엔진이 내부적으로 여러 변형 쿼리로 펼침(**쿼리 팬아웃**)
2. 각 변형이 의미 벡터 공간에서 가까운 **패시지(문단·문장 단위)** 를 검색(**덴스 리트리벌**)
3. 검색된 패시지를 합성해 답변 문장을 생성
4. 답변에 출처 링크(인용) 표시

인용 확률은 `P(팬아웃 변형 일치) × P(벡터 검색 채택) × P(생성 단계 선택)`의 곱으로 이해하면 됩니다. 한 단계만 약해도 최종 노출이 무너집니다.

## SEO vs AEO vs GEO

| 차원 | SEO | AEO | GEO |
|---|---|---|---|
| **최적화 대상** | URL(블루 링크) 랭킹 | 직접 답변 박스로의 추출 | AI 답변 속 브랜드 언급·인용 |
| **대표 표면** | Google/Bing 자연 검색 | 스니펫, PAA, 음성, AI Overviews | ChatGPT, Perplexity, Gemini, Claude |
| **성공 지표** | 순위, 유기 트래픽, CTR | 스니펫 점유율, 답변 소유 | 인용 빈도, SOV, 감성 |
| **콘텐츠 형태** | 키워드 기반 페이지 전체 | Q&A 단위, FAQ/HowTo | 엔티티 풍부, 통계·인용문, 시맨틱 클러스터 |
| **신뢰 신호** | 백링크, 도메인 권위 | 인용 권위, E-E-A-T | 공동 인용(합의), 서드파티 멘션 |

실무 우선순위는 **유기 존재감이 없으면 SEO 먼저 → 사실형 쿼리가 많으면 AEO 우선 → 구매 전 리서치 고객층이면 GEO 우선**입니다. 2026년 표준은 "SEO 기반 + AEO 구조 + GEO 측정"을 동시에 하는 것입니다.

## GEO 최적화 전략

### 1. 구조화 데이터 (JSON-LD)

- 핵심 스키마: `Organization`·`Article`·`FAQPage`·`HowTo`·`Product`·`Person`·`BreadcrumbList`
- `@id`·`sameAs`(위키백과·LinkedIn·Crunchbase)로 공개 지식 그래프에 연결
- 콘텐츠와 일치하지 않는 스키마는 역효과이므로 주의

### 2. 인용 가능한 콘텐츠 (프린스턴 9개 기법 중 상위 3)

| 기법 | 효과 |
|---|---|
| Cite Sources (출처 인용) | +30% 이상, 사실형 질문에 최고 |
| Quotation Addition (권위 인용문) | +41%, 사람·역사·설명형 |
| Statistics Addition (통계 추가) | +37%, 법·의견형 |
| **Keyword Stuffing** | **-10% (역효과)** |

### 3. 브랜드 엔티티와 E-E-A-T

- 브랜드명·로고·설명·주소가 자사 사이트와 외부 프로필 전반에서 동일해야 AI가 브랜드를 '하나의 대상'으로 식별합니다.
- 통계 출처 링크, 학술 논문 인용, 1차 데이터, 사례 회사명을 본문 곳곳에 분산 배치합니다.
- 신선도 관리: 2개월 내 업데이트 페이지가 인용률이 높습니다.

## GEO 측정 지표

| 지표 | 정의 |
|---|---|
| **인용 빈도** | 타겟 쿼리에서 우리 콘텐츠가 AI 출처로 등장하는 비율 |
| **SOV** | 같은 쿼리에서 경쟁사 대비 우리 브랜드 언급 비율 |
| **인용 감성** | 긍정/중립/부정 맥락에서의 언급 |
| **AI 유입 트래픽·전환** | GA4 커스텀 채널 + UTM으로 분리 측정 |

국내 측정 인프라 비대칭: 구글은 Search Console 생성형 AI 성과 보고서로 확인 가능하지만, **네이버 AI 브리핑은 인용 보고서가 없어** '무엇이 인용되는가'의 규칙(경험·전문성·구조)에 맞춰 콘텐츠를 정비하는 이원 전략이 필요합니다.

## 실무 체크리스트

**진단(1~2주)**
- [ ] robots.txt에서 AI 크롤러(GPTBot·PerplexityBot·ClaudeBot·Google-Extended·Gemini·네이버 Yeti) 허용 확인
- [ ] GA4에 AI/LLM 커스텀 채널 그룹 + UTM 태깅 구성
- [ ] 타겟 쿼리 20~50개 정의, AI 엔진에 주 1회 질의해 기준선 확보

**최적화(1~3개월)**
- [ ] 핵심 페이지에 JSON-LD + sameAs 적용
- [ ] 질문형 H2 + 결론 우선 2~4문장 답변 블록 구조로 개편
- [ ] 패시지마다 출처 있는 통계·전문가 인용문·신뢰 출처 링크 1개씩 추가
- [ ] 서드파티 멘션(라운드업·비교 기사·레딧) 확보
- [ ] 콘텐츠 2개월 이내 갱신 주기 수립

**측정·반복(지속)**
- [ ] 주간 인용 빈도·SOV·감성, 월간 AI 유입 트래픽·전환 측정
- [ ] 네이버 AI 브리핑 대상: 직접 경험·주제 집중도·진정성 규칙에 맞는 콘텐츠 운영

> 참고: Google은 2026년 5월 공식 가이드에서 "생성형 AI 검색 최적화는 여전히 SEO"라고 명시했지만, 이는 구글에만 적용되며 ChatGPT·Perplexity 등은 다른 규칙을 가질 수 있습니다.
