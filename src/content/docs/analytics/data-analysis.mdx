# 데이터 분석 방법 (탐색·퍼널·코호트·세그먼트)

GA4의 **탐색(Explore)** 탭은 표준 보고서로 답할 수 없는 심층 질문을 분석하는 도구입니다. 마케팅 의사결정은 "예쁜 리포트"가 아니라 **데이터가 어디서 끊기는지**를 찾는 데서 시작합니다.

## 탐색 분석 기법

| 기법 | 용도 |
|---|---|
| 자유 형식 (Free form) | 분할표·차트로 자유롭게 집계 |
| 동질 집단 (Cohort) | 공통 특성(최초 획득일 등)을 가진 그룹의 행동·리텐션 분석 |
| 유입경로 (Funnel) | 단계별 전환·이탈 지점 시각화 |
| 경로 탐색 (Path) | 사용자 행동 경로 시각화 |
| 세그먼트 중복 (Segment overlap) | 여러 세그먼트 간 교집합·차이 파악 |
| 사용자 개별화 (User explorer) | 개별 사용자 활동 상세 분석 |
| 사용자 전체 기간 (User lifetime) | 고객 생애 가치·장기 행동 분석 |

## 퍼널 분석 (Funnel Analysis)

- **유입경로 탐색 분석** 기법으로 사용자가 전환까지 거치는 단계별 유입·이탈을 분석합니다.
- 예: 상품 조회 → 장바구니 추가 → 결제 시작 → 구매 완료
- 각 단계의 전환율과 이탈 지점을 파악해 **병목 구간**을 개선합니다.
- 표준 보고서 중 '구매 여정(Purchase journey)', '결제 여정(Checkout journey)'도 퍼널 형태의 전자상거래 보고서입니다.

**퍼널 분석 순서**
1. 핵심 전환 단계 정의 (비즈니스 목표 기반)
2. 단계별 전환율·이탈률 집계
3. 가장 큰 이탈 구간 식별
4. 가설 수립 → 개선(A/B 테스트) → 재측정

## 코호트 분석 (Cohort Analysis)

- **동질 집단 탐색 분석** 기법으로, 특정 기간(일·주·월)에 처음 획득된 사용자 그룹(코호트)의 시간 경과별 유지율·재방문을 분석합니다.
- 예: 1월 첫 주 획득 코호트의 4주차 잔존율 vs 2월 첫 주 코호트의 4주차 잔존율
- 구독·앱·이커머스 비즈니스에서 **리텐션 건강도를 조기에 감지**하는 데 유용합니다.
- 1~3개월차 이탈이 가장 크므로 조기 참여 캠페인과 짝지어 해석합니다.

## 세그먼트 (Segments)

세그먼트는 탐색 분석에서 사용할 데이터의 하위 집합입니다.

- GA4는 **사용자(user), 세션(session), 이벤트(event)** 3가지 유형의 세그먼트를 지원합니다.
- 조건은 AND/OR 로직의 조건 그룹으로 조합, 사용자 세그먼트는 **시퀀스(순차 조건)** 도 설정 가능합니다.
- 로컬 세그먼트(작성자만 사용)와 속성 수준 세그먼트(속성 전체 공유)로 나뉩니다.
- 주의: 세그먼트는 **잠재고객(Audience, 광고 타겟팅용)과 유사하지만 다른 기능**이며, 동일 조건이라도 집계 수가 다를 수 있습니다.

## 마케팅 분석 실무 팁

- **채널별 성과 분리**: GA4 획득 보고서 + UTM 파라미터로 채널 기여를 구분
- **전환 기여 확인**: 관리자 → 기여 분석에서 어트리뷰션 모델(마지막 클릭 vs 데이터 기반) 검토
- **AI 검색 채널 분리**: `chat.openai.com`, `perplexity.ai`, `gemini.google.com` 등을 커스텀 채널 그룹으로 정의
- **캠페인 네이밍 표준화**: `source_medium_campaign` 규칙 통일 → 데이터가 끊기는 지점 제거
- **CRM·광고 데이터 연결**: 어트리뷰션의 마지막 단계는 광고 플랫폼 데이터와 CRM 매출의 조인
- **측정은 학습 중심**: 톱·워스트 콘텐츠를 포맷·주제·채널·훅으로 분해해 "다음에 무엇을 바꿀까"를 정합니다.

## 의사결정으로 이어지는 분석 흐름

1. 표준 보고서로 이슈 감지 (예: 획득 트래픽 급증)
2. 탐색 분석으로 원인 세분화 (유입 채널·세그먼트·코호트 교차)
3. 퍼널 분석으로 병목 구간 특정
4. 세그먼트로 영향 대상(기기·신규/재방문) 분리
5. 가설 → 실험(A/B) → 재측정 → 예산·콘텐츠 개선 반영

## 실무 체크리스트

**탐색·퍼널**
- [ ] 핵심 전환 단계 정의 (조회→장바구니→결제→구매 등)
- [ ] 퍼널 탐색 분석으로 단계별 전환율·이탈 지점 확인
- [ ] 최대 이탈 구간에 가설 수립, A/B 테스트 실행

**코호트**
- [ ] 주·월 단위 획득 코호트의 잔존율 추적
- [ ] 1~3개월차 조기 이탈 구간 파악 → 조기 참여 캠페인 연계
- [ ] D1/D7/D30 리텐션 기준선 확보

**세그먼트**
- [ ] 신규/재사용, 모바일/데스크톱 등 핵심 세그먼트 정의
- [ ] 조건 그룹 AND/OR 로직 검증
- [ ] 세그먼트와 잠재고객(Audience) 혼용 주의 — 용도 구분

**기반**
- [ ] UTM 태깅 규칙 표준화, 캠페인 네이밍 통일
- [ ] AI 검색 채널 커스텀 채널 그룹 구성
- [ ] 기여 분석 모델 설정 검토
- [ ] 광고 플랫폼 데이터 ↔ CRM 매출 조인 여부 점검
- [ ] 주 1회 이상 검색 성과·획득 보고서 모니터링
