# 데이터 분석

마케팅 성과를 **데이터로 측정하고 해석**하는 카테고리입니다.
GA4 설정과 주요 보고서, 퍼널·코호트 분석, 세그먼트 활용법을 마케터 관점에서 다룹니다.

## 주제 클러스터

- [GA4 기초](/analytics/clusters/ga4-foundations/) — GA4 설정·이벤트·핵심 보고서를 이해하고 활용하는 기초를 다루는 클러스터.
- [마케팅 분석](/analytics/clusters/marketing-analysis/) — 캠페인·채널 데이터를 수집·분석해 마케팅 의사결정을 내리는 분석 실무를 다루는 클러스터.

## 이 카테고리에서 다루는 주제

- GA4 기초: 이벤트 기반 모델과 핵심 지표
- GA4 설정: 태그 설치, 이벤트 추적, 전환
- 퍼널 분석, 코호트 분석, 세그먼트
- 마케팅 성과 리포트 만들기
- 마케팅 용어사전 (핵심 용어 정리)
