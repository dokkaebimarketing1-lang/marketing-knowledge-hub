# 퍼포먼스 마케팅

광고비 대비 **성과(매출, 전환)** 를 측정하고 최적화하는 **퍼포먼스 마케팅** 카테고리입니다.
ROAS, CAC, LTV 같은 핵심 지표의 정의부터 채널별 광고 운영, 리텐션 전략까지 다룹니다.

## 주제 클러스터

- [성과 지표](/performance/clusters/performance-metrics/) — ROAS·CPA·CAC 등 광고 성과 지표의 산정과 해석을 다루는 클러스터.
- [리텐션 마케팅](/performance/clusters/retention-marketing/) — 기존 고객의 재구매 유도와 이탈 방지로 수익을 극대화하는 리텐션 전략을 다루는 클러스터.

## 이 카테고리에서 다루는 주제

- 핵심 지표: ROAS, CAC, LTV, CPA 계산법
- 채널별 광고 운영: 메타, 구글, 카카오
- A/B 테스트와 광고 최적화
- 리텐션 마케팅과 고객 생애주기
- 마케팅 자동화와 그로스해킹
