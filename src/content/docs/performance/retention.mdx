# 리텐션 마케팅 (고객 유지와 윈백)

**리텐션 마케팅(Retention Marketing)** 은 기존 고객을 유지·재구매·재계약·충성화하기 위한 생애주기 기반 커뮤니케이션 전략입니다. 획득이 "고객을 데려오는 것"이라면, 리텐션은 "고객이 머물고 더 쓰게 하는 것"입니다.

## 왜 리텐션인가

- 신규 고객 획득 비용은 유지 비용의 **5~25배**
- 유지율을 5% 개선하면 이익이 **25~95%** 증가할 수 있습니다.
- 유료 채널 경쟁이 심화될수록 **리텐션 ROI가 획득 ROI보다 커집니다.**

## 고객 생애주기 (6단계)

1. **인지(Awareness)**: 브랜드 최초 접촉
2. **획득(Acquisition)**: 가입/다운로드/신청 등 자격 행동
3. **온보딩(Onboarding)**: 제품 사용법 학습, 조기 가치 경험
4. **참여(Engagement)**: 습관적 사용, 사용 빈도·깊이 증가
5. **유지(Retention)**: 이탈 방지, 충성도 강화
6. **옹호(Advocacy)**: 추천, 리뷰, 앰버서더

각 단계마다 다른 메시지, 채널, 성공 지표가 필요합니다. 실무에서는 **온보딩 → 참여 → 리텐션 → 윈백** 4단계 프레임워크로 압축해 운영합니다.

## 리텐션 전략

1. **온보딩 최적화**: 첫 경험에서 가치를 빠르게. 웰컴 시퀀스, 가이드 투어, 첫 성공 체크리스트.
2. **개인화**: 76%의 소비자가 "내 니즈를 이해하는 회사"에 충성도를 느낍니다. 구매 이력·행동 기반 오퍼.
3. **라이프사이클 자동화**: 웰컴, 구매 후, 재구매 리마인더, 리뷰 요청, 재입고 알림, 윈백 시퀀스.
4. **멤버십/로열티 프로그램**:
   - 포인트 기반: 구매 시 적립·사용
   - **티어(등급) 기반**: 높은 등급일수록 혜택 증가 (세포라의 Insider/VIB/Rouge 3티어가 대표 사례 — 등급 달성 직전 고객의 지출 집중 유도)
   - 주의: 유효기간 지나 빨리 소멸하는 포인트, 과도한 적립 요건은 역효과
5. **리퍼럴(추천) 프로그램**: 양방향 인센티브. 추천 고객은 유지율·LTV가 더 높은 경향.
6. **커뮤니티**: 거래 밖의 고객 간 연결 공간 — 전환 비용(switching cost)을 만듭니다.
7. **사후 마케팅(Post-purchase)**: 배송/사용 안내, 리뷰 유도, 업셀/크로스셀.
8. **UGC 활용**: 고객 리뷰·콘텐츠를 마케팅 소재로 재사용.

## 이탈 방지와 윈백

- **이탈 예측**: AI/예측 분석으로 이탈 위험 고객을 사전 식별 → 적시 리타겟팅(할인, 교육 콘텐츠, 체크인 캠페인).
- **코호트 리텐션 곡선**: 구독 사업은 **1~3개월차 이탈이 가장 크므로** 조기 참여 캠페인이 핵심입니다.
- **윈백 시퀀스**: 휴면 고객 대상 "다시 찾아온 이유" 메시지 + 복귀 혜택.
- **서비스 품질·UX 개선**: 결제 옵션 다양화, 셀프서비스, 유연한 계정 설정으로 마찰 제거.

## 리텐션 성과 지표

| 지표 | 정의 |
|---|---|
| 유지율 | 1 − 이탈률 |
| 이탈률 | (기간 내 이탈 고객 ÷ 기간 시작 고객) × 100 |
| 재구매율 | 일정 기간 내 재구매한 고객 비율 |
| LTV / LTV:CAC | 고객 생애 가치와 획득비 대비 비율 |
| NPS / CSAT | 충성도·만족도 |
| D1/D7/D30 리텐션 | 코호트별 일 단위 잔존율 (앱) |

**LTV 계산 예시**
- 역사적 LTV = 평균 구매가 × 구매 빈도 × 고객 수명 (예: 4만 원 × 연 3회 × 3년 = 36만 원)
- 구독형 LTV = (ARPU × 마진율) ÷ 이탈률
- 예측 LTV = 코호트 분석·생존분석·ML 모델 기반 추정

LTV는 매출 기준이 아니라 **마진(공헌이익) 기준**으로 비교해야 CAC와 정확히 대응합니다. 매출 기준 LTV는 유닛 이코노믹스를 과대평가합니다.

## 리텐션 대시보드 구성

- **코호트 리텐션 표**: 첫 구매 월별 잔존율 매트릭스 (구독·앱의 건강도 스캔)
- **이탈 위험 신호**: 30일 미접속, 구매 주기 경과, 기능 미사용 — 자동 세그먼트 생성
- **리텐션 퍼널**: 온보딩 완료 → 첫 구매 → 재구매 → 윈백 응답률
- **채널별 리텐션**: 획득 채널별 90일 리텐션 비교 → 채널 품질 판단 (저품질 획득 채널 예산 조정)

## 실무 체크리스트

- [ ] 웰컴 시퀀스(온보딩 이메일·가이드) 구축 — "빠른 가치" 제공
- [ ] 제품 행동 모니터링으로 미사용 기능·루틴화 유도
- [ ] 구매 후 30일 뒤 재구매 리마인더·쿠폰 자동 발송
- [ ] 장바구니 이탈·결제 시작 이탈 시퀀스 운영
- [ ] 코호트별 D1/D7/D30 리텐션 추적, 1~3개월차 조기 참여 캠페인 강화
- [ ] 이탈 위험 고객 세그먼트 정의 + 윈백 시퀀스 발동 조건 설정
- [ ] 로열티 프로그램 설계 (포인트/티어, 소멸 조건·적립 요건 검토)
- [ ] 리퍼럴 프로그램 양방향 인센티브 설정
- [ ] NPS·CSAT 주기 측정, 피드백을 전략에 환류
- [ ] 구매 완료 30일 오디언스는 리타겟팅에서 제외 (예산 낭비 방지)
