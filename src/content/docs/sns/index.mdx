# SNS 마케팅

인스타그램, 유튜브, 틱톡, 라이브커머스 등 **SNS 채널별 특성과 운영 전략**을 다루는 카테고리입니다.
알고리즘의 작동 원리, 숏폼 콘텐츠, 인플루언서·뮤즈 마케팅, SNS 광고 운영까지 실무 가이드를 제공합니다.

## 주제 클러스터

- [인스타그램 마케팅](/sns/clusters/instagram-marketing/) — 인스타그램 피드·릴스·스토리를 활용한 브랜드 운영과 캠페인 전략을 다루는 클러스터.
- [유튜브 마케팅](/sns/clusters/youtube-marketing/) — 유튜브 검색·추천 알고리즘 노출과 영상 콘텐츠 전략을 다루는 클러스터.

## 이 카테고리에서 다루는 주제

- 채널별 특성 비교와 선택 기준
- 인스타그램: 릴스, 스토리, 뮤즈 마케팅
- 유튜브: 채널 운영, 쇼츠, 광고 전략
- 라이브커머스 운영과 플랫폼별 전략
- SNS 광고: 타게팅, 리타겟팅, 픽셀
