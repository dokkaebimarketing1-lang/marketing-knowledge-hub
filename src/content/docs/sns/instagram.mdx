# 인스타그램 마케팅 (릴스·스토리·광고)

인스타그램은 국내 광고 도달 약 2,560만 명(인구 대비 49.5%), 최대 연령층은 25~34세(37.7%)로 **거의 모든 업종에서 1순위로 고려되는 SNS 채널**입니다. 2026년에는 **릴스가 발견의 중심**이 됐습니다.

## 2026년 인스타 알고리즘 이해

인스타그램은 **포맷별로 별도 알고리즘**을 사용합니다: 피드(관계 중심), 릴스(엔터테인먼트·발견), 스토리(최신성·관계 강도), Explore(관심사 기반).

- **릴스 1순위 신호 = 완료율**, 2순위 = **DM 공유율**. 좋아요보다 공유·저장이 강한 가중치입니다.
- **"Your Algorithm" 업데이트**: 사용자가 릴스 피드에서 보고 싶은 주제를 직접 입력 — 능동적 선호 신호.
- **원본 콘텐츠 정책 확대**: 리포스트 위주 계정을 추천에서 제외. 원본 콘텐츠가 리포스트 대비 40~60% 더 배포됩니다.
- **조회수(View) 지표 통합**: 노출(Impressions)이 Views로 통합, 재시청 포함 카운트 — 예전 노출 수치와 직접 비교 금지.
- **양방향 대화 신호**: DM·댓글·스토리 답장에 응답할수록 팔로워 피드 상단 노출. "응답 = 랭킹 신호".
- **Trial Reels**: 비팔로워에게 먼저 테스트 노출 후 성과 좋은 릴스만 메인 발행·광고로 승격.
- **틱톡 워터마크 디부스트**: 워터마크 있는 영상은 추천에서 필터링됩니다.
- **AI 생성물 미공개 시 도달 제한**: AI 생성 이미지·영상은 공개 여부가 랭킹에 반영됩니다.

## 릴스 운영 전략

- **권장 길이 7~15초**, 처음 1.7초 안에 질문·패턴 인터럽트로 후킹
- **음성/보이스오버 활용**: 음악만 있는 릴스보다 참여율 +5.6%, 시청 시간 +25%
- **루프 디자인**: 반복 재생 신호를 노린 엔딩
- **주 4~7개 Trial Reels 테스트 → 승자에 광고 예산 투입**
- 해시태그: 3~5개 핵심 + 니치 태그. 20개 이상은 도달 감소 경향
- 틱톡에서 발행한 영상을 그대로 올리지 말 것 (워터마크 제거 후 재업로드)

## 스토리와 라이브

- 스토리는 팔로워 기반이지만 **전환 의도가 가장 높은 지면**입니다. 링크 스티커·투표·퀴즈로 대화 신호를 만듭니다.
- **디자인 안전 영역**: 상단 150px(브랜드명/프로필), 하단 120~150px(스와이프 CTA).
- 스토리 광고 사양: 9:16 세로, 5~15초 권장.
- **인스타 라이브 광고 (2026.3 한국 출시)**: 라이브 방송 화면 그대로 광고 노출, 라이브커머스·이벤트에 높은 신뢰도.

| 지표 | 수치 |
|---|---|

| 캐러셀 참여율 | 0.52% (포맷 중 최고) |
| 릴스 참여율 | 0.50% |
| 릴스 도달(단일 이미지 대비) | 4배 |
| 릴스 vs 스토리 참여 | +22% |

## 측정 (인사이트 기준)

| 지표 | 의미 | 측정 주기 |
|---|---|---|
| 조회수(View) | 재시청 포함 통합 지표 (구 노출과 직접 비교 금지) | 릴스 발행 후 3~5일 |
| 도달 | 고유 사용자 수, 비팔로워 도달 비중 확인 | 주간 |
| 평균 시청 시간 / 재생률 | 릴스 완료율의 구성 요소 | 릴스별 |
| DM 공유율(Sends per Reach) | 릴스 랭킹 2순위 신호 | 릴스별 |
| 저장·공유 | 좋아요보다 강한 가중치 | 게시물별 |
| 양방향 대화 수 | DM·댓글·스토리 답장 응답률 — 랭킹 신호 | 주간 |

측정 원칙: 채널 간 "조회수" 지표는 정의가 다르므로 단순 합산하지 말고, **자기 채널 평균 대비 상대 개선**을 기준선으로 삼습니다.

## 광고 운영 (메타 중심)

- **릴스 광고 스펙**: 9:16 강제, 1080×1920px, 15~30초 권장(60초 초과 시 완료율·CPM 급락), 사운드 온 +35% 참여, 상·하단 14% 안전 영역.
- **Advantage+ 캠페인(ASC)**: AI가 타게팅·크리에이티브·예산을 자동 최적화 — 수동 세팅보다 ROAS 우위 보고.
- **맞춤 타겟**: 웹사이트 방문 30~60일 / 장바구니 7~14일 / 결제 7일.
- **유사 타겟**: 구매자 맞춤 타겟 기반 1% 유사 타겟이 관심사 타게팅 대비 ROAS 30~40% 우위.
- **픽셀 + CAPI**: iOS 제한을 보완하는 서버 측 이벤트 전송이 데이터 정확도의 핵심.

## 실무 체크리스트

- [ ] 비즈니스 프로필 전환, 한 줄 포지셔닝 문구 설정
- [ ] 프로필 링크 1개 + 하이라이트 정리
- [ ] 주 4~7개 Trial Reels 테스트 → 승자 승격
- [ ] 릴스 7~15초, 첫 1.7초 훅, 루프 엔딩, 자막 포함
- [ ] 음성/보이스오버 활용, 트렌딩 음원 + 니치 적합성 확인
- [ ] 캐러셀 주 1~2회 (스와이프 유도), 20장 활용
- [ ] 스토리 매일 1회 이상 + 링크 스티커·투표·퀴즈
- [ ] 댓글·DM 24시간 내 응답 (양방향 대화 신호)
- [ ] 해시태그 3~5개, 틱톡 워터마크 제거, 리포스트 주의
- [ ] AI 생성물 공개 여부 확인
- [ ] 픽셀 + CAPI 설치, UTM·쿠폰 코드로 전환 추적 구축
