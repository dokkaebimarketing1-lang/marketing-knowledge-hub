# 콘텐츠 마케팅

콘텐츠를 통해 고객을 유입·육성·전환시키는 **콘텐츠 마케팅** 카테고리입니다.
콘텐츠 전략 수립, 퍼널별 콘텐츠 기획, 스토리텔링, 이메일·알림톡 마케팅, 성과 측정까지 다룹니다.

## 주제 클러스터

- [콘텐츠 전략](/content/clusters/content-strategy/) — 브랜드 목표를 달성하는 콘텐츠 기획·운영 전략을 다루는 클러스터.
- [라이프사이클 메시징](/content/clusters/lifecycle-messaging/) — 고객 여정 단계별 이메일·메시지 커뮤니케이션 설계로 전환과 유지를 이끄는 클러스터.

## 이 카테고리에서 다루는 주제

- 콘텐츠 마케팅 전략 수립 (목표·페르소나·채널)
- 퍼널별 콘텐츠: TOFU·MOFU·BOFU
- 스토리텔링과 브랜드 콘텐츠
- 이메일·카카오 알림톡 마케팅
- 콘텐츠 성과 측정과 KPI
