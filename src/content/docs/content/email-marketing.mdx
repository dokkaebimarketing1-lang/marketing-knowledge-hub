# 이메일·카카오 알림톡 마케팅

이메일과 카카오 알림톡·친구톡은 **기존 고객·구독자에게 반복 매출을 만드는 대표 CRM 채널**입니다. 획득 비용이 치솟는 환경에서 리텐션·재구매를 이끄는 핵심 지면입니다.

## 이메일 마케팅 핵심 지표와 공식

| 지표 | 공식 |
|---|---|
| **오픈율** | (오픈한 수신자 ÷ 발송 성공 수신자) × 100 |
| **클릭률(CTR)** | (클릭한 수신자 ÷ 오픈한 수신자) × 100 |
| **전환율** | (이메일 유입 전환 ÷ 클릭 수) × 100 |
| 반송률 / 스팸 신고율 / 수신거부율 | 발송 품질·평판 관리 지표 |

## 한국 이메일 벤치마크 (스티비 2025 데이터)

| 구독자 규모 | 오픈율 | 클릭률 |
|---|---|---|
| 1~500명 | 40.7% | 7.1% |
| 1~5,000명 | 27.4% | 3.4% |
| 50,000명 이상 | 11.8% | 0.7% |

- 구독자 규모가 10배 커지면 오픈율·클릭률이 2배 이상 하락 → **세그먼테이션의 중요성**.
- **자동화 이메일은 일반 발송 대비 오픈율 1.6배, 클릭률 3.7배** 높습니다 → 웰컴 시퀀스 등 자동화가 성과의 핵심.

## 이메일 마케팅 원칙

1. **세그먼테이션**: 구독자 규모·행동·구매 이력 기반으로 리스트 분할
2. **자동화 시나리오**: 웰컴(구독 시), 가입, 구매 후, 재구매 리마인더, 장바구니 이탈, 윈백, 리뷰 요청
3. **A/B 테스트**: 제목, 발송 시간, 콘텐츠 레이아웃 지속 테스트 (스티비 사례: 제목 A/B 테스트로 오픈율 +1.5%p)
4. **오픈율 한계 인식**: Apple MPP(Mail Privacy Protection) 등으로 오픈율의 참여 지표 가치가 하락 — 클릭·전환과 함께 해석
5. **휴면 구독자 정리**: 참여하지 않는 구독자 제거로 발신자 평판(sender reputation)과 ROI 개선

## 카카오 알림톡 vs 친구톡

| 구분 | 알림톡 | 친구톡 |
|---|---|---|
| 성격 | **정보성 메시지**(주문·결제·배송 등) | **광고성 메시지**(프로모션, 홍보) |
| 수신 동의 | 채널 추가 없이 발송 가능 (광고성 정보 예외) | 카카오 채널 추가 고객에게만 |
| 심사 | 카카오 내부 심사 통과한 **템플릿** 필수 | 템플릿 불필요 |
| 표기 | (광고) 표기 불필요 | 메시지 앞에 (광고) 표기 |
| 멀티미디어 | 제한적 | 이미지/영상/GIF 가능 |

**활용 시나리오**
- 알림톡: 주문 확인, 결제 완료, 배송 안내, 예약 알림, 본인인증 — **거래 기반 자동 발송**(CRM/커머스/물류 시스템 연동)
- 친구톡: 프로모션, 신제품 출시, 재입고 알림, 리뷰 요청 — 이미지/영상으로 시선 유도
- 알림톡 내 '채널 추가' 버튼으로 친구톡 발송 대상(채널 친구)을 확보

**자동화 운영 (마케팅 저니)**
- 특정 행동(상품 3회 조회 후 미구매 등) 조건에서 자동 발송하는 저니 설계
- 선행 메시지 반응 여부에 따라 다음 메시지 분기
- API 연동으로 발송 대상(모수) 실시간 업데이트
- n8n + 솔라피(Solapi) 같은 자동화 툴로 워크플로우 구축 가능

## 운영 포인트

- 알림톡은 **사전 승인된 템플릿에 한해** 발송, 정보통신망법 준수 필수
- 적법한 절차로 수집된 전화번호만 사용
- 카카오 비즈니스 채널 개설(사업자등록증 필요) 후 발송 가능
- 알림톡 다이렉트 메시지 단가: 타게팅 미적용 15원/건, 타게팅 적용 20원/건 (친구톡 기준)

## 도구 선택과 자동화 구축

**주요 도구**
- 한국: 스티비(이메일/뉴스레터), 와이즈트래커(CRM·마케팅 저니), 솔라피(알림톡/문자 API)
- 오픈소스: n8n(워크플로 자동화, 400+ 통합), Mautic(마케팅 자동화·이메일 캠페인·저니 빌더)
- 엔터프라이즈: Salesforce Marketing Cloud, HubSpot, Marketo

**자동화 구축 프로세스**
1. 데이터 감사: 기존 캠페인 성과 벤치마크와 데이터 품질 점검
2. 목표에 맞는 도구 선택
3. 작게 시작해 확장: 소규모 캠페인 테스트 후 전환율·ROAS 확인 후 전사 확장
4. 인간+기계 결합: AI가 대규모 전달·최적화를, 인간이 맥락·브랜드 톤을 검증

## 실무 체크리스트

- [ ] 구독 폼 + 웰컴 시퀀스 (구독 즉시 자동 발송) 구축
- [ ] 구독자 세그먼트(신규/구매 이력/휴면) 분할
- [ ] 장바구니 이탈·결제 시작 이탈 시퀀스 운영
- [ ] 구매 후 30일 뒤 재구매 리마인더·리뷰 요청 자동화
- [ ] 휴면 구독자 윈백 시퀀스 + 복귀 혜택 설정
- [ ] 제목 A/B 테스트, 발송 시간 테스트 지속
- [ ] Apple MPP 대비 클릭·전환 중심 해석
- [ ] 알림톡 템플릿 심사 통과 여부·표기 준수 확인
- [ ] 친구톡 대상(채널 친구) 확보 경로 운영
- [ ] 수신거부율·스팸 신고율 모니터링, 휴면 리스트 정리
