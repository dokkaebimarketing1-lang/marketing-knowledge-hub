# SEO 기초 (온페이지·오프페이지·기술적 SEO)

**SEO(Search Engine Optimization, 검색 엔진 최적화)** 는 사용자가 검색 포털에서 특정 키워드를 검색할 때 자사 브랜드·상품·콘텐츠를 자연 검색 결과 상단에 노출시켜 유입과 전환을 만드는 마케팅입니다. SEO는 작업 범위에 따라 **온페이지, 오프페이지, 기술적 SEO** 세 가지로 나뉩니다.

## SEO vs 키워드 광고 (SEM)

| 구분 | SEO | 키워드 광고 (SEM) |
|---|---|---|
| 방식 | 자연 검색 노출 (유기적) | 유료 광고 노출 |
| 비용 | 광고비 없음 (시간·인력 투자) | 클릭당 비용(CPC) 지불 |
| 소요 시간 | 수주~수개월 | 집행 즉시 |
| 지속성 | 장기 자산 | 예산 중단 시 노출 종료 |

국내 검색 시장은 네이버가 약 60% 내외로 1위이며, 결과가 블로그·카페·지식iN·쇼핑·뉴스·웹문서 등 **섹션별로 분리**되는 통합 검색 구조입니다. 실무적으로는 **네이버 플랫폼 우선 전략 + 구글 웹사이트 SEO 병행**이 일반적입니다.

## 1. 온페이지 SEO (페이지 내부)

| 요소 | 실무 권장 기준 |
|---|---|
| Title 태그 | 페이지마다 고유, 핵심 키워드 앞쪽, 한글 30~40자 이내 |
| Meta Description | 페이지마다 고유, 한글 70~80자 이내, 클릭 유도형 |
| H1~H3 헤딩 | H1은 페이지당 1개, 질문형 소제목 권장 |
| 본문 콘텐츠 | 검색 의도 부합, 키워드 자연 배치(스터핑 금지), 1,500자 이상 |
| URL 구조 | 짧고 설명적, 핵심 키워드 포함 |
| 이미지 | Alt 텍스트, WebP 압축, 키워드 포함 파일명 |
| 내부 링크 | 중요 페이지 최소 1회 이상, 의미 있는 앵커 텍스트 |

## 2. 오프페이지 SEO (외부 신호)

- **백링크(역링크)**: 신뢰할 수 있고 관련성 높은 사이트에서 링크 확보
- **브랜드 언급/인용**: 포털·커뮤니티·뉴스에서 자연스러운 언급
- **소셜 신호**: 콘텐츠 공유, SNS 활동
- **게스트 블로깅/인플루언서 협업**: 노출 확대 + 링크 확보
- **평판 관리(ORM)**: 리뷰·언급 모니터링과 긍정 평판 유지

> 한국 시장에서는 해외식 백링크 빌딩보다 **네이버 블로그/카페 생태계 내 언급과 유입**이 더 큰 비중을 차지합니다. 무분별한 역링크 구매는 저품질 신호입니다.

## 3. 기술적 SEO (크롤링·인덱싱)

- SSL(HTTPS) 적용 — 미적용 시 브라우저 경고 + 순위 불이익
- 모바일 반응형 — 네이버 검색의 약 75~80%가 모바일
- 로딩 속도 — Core Web Vitals: LCP 2.5초 이내, CLS 0.1 이내 목표
- XML 사이트맵 + RSS — 구글 서치콘솔과 네이버 서치어드바이저에 제출
- robots.txt — 네이버봇(Yeti)·구글봇 크롤링 허용 확인
- 중복/노이즈 페이지 관리 — noindex, canonical, 리다이렉트
- 구조화 데이터 — JSON-LD 형태로 FAQ, Article, Product 등 적용

## 네이버 SEO 특성: C-Rank + D.I.A.

네이버 블로그/카페 검색 순위는 **"누가 썼는가(채널 신뢰도)"와 "글이 얼마나 도움이 되는가(문서 품질)"** 두 축으로 결정됩니다.

- **C-Rank (Creator Rank)**: Context(주제 집중도)·Chain(내부 연결)·Authority(권위 연결) — 잡블로그보다 **한 분야를 깊이 파는 블로그**가 유리
- **D.I.A. (Deep Intent Analysis)**: 검색 의도 부합도, 독창성, 정보 가치 — 2026년에는 **직접 체험·고유 이미지**를 핵심으로 평가

2025년 말 도입된 **Next N Search**(신경망 매칭)와 **에어서치(AirSearch)** 개인화로, 키워드가 직접 없어도 문맥적 의미가 맞으면 노출되고 같은 키워드도 사용자별 결과가 달라집니다.

## 네이버 vs 구글 비교

| 구분 | 구글 | 네이버 |
|---|---|---|
| 검색 결과 구조 | 단일 리스트 | 섹션별 분리 (블로그, 카페, 웹문서 등) |
| 평가 기준 | 콘텐츠 품질 + 링크 기반 (E-E-A-T) | 작성자 신뢰도 + 플랫폼 친화도 (C-Rank, D.I.A.) |
| 순위 유지 | 한번 오르면 장기 유지 경향 | 최신성 영향 커 지속 관리 필요 |
| 웹마스터 도구 | 구글 서치콘솔 | 네이버 서치어드바이저 |

## 2026년 변화: AI 검색 대응

네이버 AI 브리핑(월 3,000만 명, 인용의 최대 70%가 네이버 UGC)·AI 탭이 검색의 중심이 됐습니다. SEO의 핵심 목표가 "순위 노출"에서 **"AI 브리핑/AIO 인용"** 으로 확장됐습니다.

## 실무 체크리스트

**기본 점검**
- [ ] 네이버 서치어드바이저 + 구글 서치콘솔 사이트 등록·소유권 확인
- [ ] XML 사이트맵 + RSS 제출 (양쪽)
- [ ] robots.txt에서 Yeti·구글봇 크롤링 허용, SSL 적용
- [ ] 모바일 반응형 + Core Web Vitals 점검
- [ ] 페이지별 고유 Title/Description/H1(1개) 확인

**콘텐츠 점검**
- [ ] 핵심 키워드를 제목 앞부분에 1회 배치 (30~40자 이내)
- [ ] 본문 1,500자 이상, 소제목(H2/H3) 구조화, 두괄식 첫 문단
- [ ] 키워드 자연 배치 3~5회 + 동의어·관련 키워드 혼합
- [ ] FAQ 섹션 3~5개, 수치·출처 명시
- [ ] 직접 촬영 원본 이미지 5장 이상 + Alt 텍스트
- [ ] 카테고리 주제 일관성(2~3개 이내), 주 2~3회 꾸준한 발행
- [ ] 발행 후 24시간 내 초기 반응 + 서치어드바이저 색인 요청
