# 키워드 광고 실무 (네이버 파워링크 · 구글 애즈)

**키워드 광고**는 사용자가 특정 키워드를 검색했을 때 광고를 상단에 노출시키고 **클릭당 비용(CPC)** 을 지불하는 검색 광고입니다. 국내에서는 네이버 검색광고(파워링크)와 구글 애즈가 양대 축입니다.

## 광고 구조: 캠페인 → 광고그룹 → 키워드/소재

두 플랫폼 모두 **캠페인(목표) → 광고그룹(타게팅·예산) → 키워드/소재(크리에이티브)** 의 3단계 구조입니다. 노출 순위는 최고 입찰가가 아니라 **입찰가 + 광고 품질 요소**(검색어-랜딩페이지-소재 연관도, 실시간 사용자 반응)의 복합 결과로 결정됩니다.

## 네이버 파워링크 (SA)

- 주요 상품: **파워링크**(사이트 검색광고), 파워콘텐츠, 쇼핑검색광고, 플레이스 검색광고
- 파워링크는 검색 결과 1위~15위까지 노출되며, 순위별 CTR과 광고비가 크게 다릅니다.

### ⚠️ 2026년 주요 변경: 품질지수 종료

- 네이버는 **2026년 7월 29일부로 파워링크 '품질지수' 제공을 종료**했습니다.
- 사유: **애드부스트(AdBoost)** 검색 기술 확대로 광고 노출이 AI 기반 요소로 결정되기 때문입니다.
- **대체 지표**: 2025년 12월 도입된 **최적화 지수 = 광고 연관지수 + 클릭 기대지수**를 사용해 광고 품질을 점검합니다.

### 파워링크 운영 팁

| 항목 | 실무 팁 |
|---|---|
| 광고그룹 | 브랜드/경쟁/정보성 키워드 유형별로 분리 관리 |
| 확장 소재 | 서브링크·추가 제목·홍보문구·전화번호로 노출 면적 확대 |
| 시간대 세팅 | 노출이 적은 시간대(주말·새벽)에 입찰 순위 상향 |
| 쇼핑검색 | 제외 키워드로 저효율 키워드 필터링 |
| 입찰 | 데이터 축적 후 자동 입찰(AI 입찰) 활용 |
| 랜딩 | 모바일 로딩 속도 + 전환 버튼 최적화 필수 |

## 구글 애즈

### 품질평가점수 (Quality Score, 1~10)

키워드 수준에서 확인 가능한 진단 도구로, 지난 90일 동안 같은 키워드의 다른 광고주와 비교해 평가합니다.

1. **예상 클릭률(CTR)**
2. **광고 관련성**
3. **방문 페이지 경험**

품질평가점수는 입찰 경매에 직접 사용되지는 않지만, 구성요소의 실시간 평가 결과가 입찰에 사용되므로 개선 대상이 됩니다.

### 구글 애즈 운영 팁 (2026)

- **자동 입찰(스마트 입찰)**: 전환 정의(Primary)를 정확히 설정해야 알고리즘이 올바른 목표를 학습합니다.
- **확장 검색(Broad Match)**: 통제 없는 확장 검색은 예산 가속 장치가 될 수 있어 주의.
- **지역 타겟팅**: "거주하거나 자주 방문하는 사용자" 설정이 지역 비즈니스 예산 낭비를 줄입니다.
- **PMax(실적 최대화)**: 브랜드 키워드가 PMax에 잠식되지 않도록 검색 캠페인과 역할 분리.
- **광고그룹 세분화**: 유사 의도 키워드를 그룹화하고 그룹별 맞춤 소재/랜딩 페이지 적용.

## 키워드 선택법 (공통)

1. **시드 키워드 → 확장**: 네이버 키워드도구/구글 키워드 플래너로 연관 키워드 확장
2. **롱테일 우선**: "제주도 여행"보다 "아이와 가기 좋은 제주도 서쪽 코스"처럼 구체적 키워드가 경쟁↓·전환↑
3. **검색 의도 분류**: 정보형 / 탐색형 / 거래형 — 의도에 맞는 콘텐츠·소재 매칭
4. **지표 확인**: 월 검색량(PC+모바일), 경쟁 강도, CPC — 블로그 SEO는 "검색량 200 이상 + 경쟁 낮음" 후보 우선
5. **시즌/트렌드 반영**: 네이버 데이터랩으로 검색 추이 확인 후 시즌 전 선제 운영
6. **자동완성어 활용**: 검색창 자동완성 추천어는 실제 세부 검색 의도

## 주요 도구

| 도구 | 제공 주체 | 특징 |
|---|---|---|
| 네이버 키워드도구 | 네이버 공식 | 무료, 월간 검색량·경쟁 강도·CPC·연관 키워드 |
| 구글 키워드 플래너 | 구글 공식 | 무료, 검색량 범위·광고 경쟁도·CPC |
| 블랙키위 | 국내 서드파티 | 월 검색량 + 월간 콘텐츠 발행량(경쟁도) 교차 확인 |
| 네이버 데이터랩 | 네이버 공식 | 검색어 트렌드, 성별·연령별·기기별 분포 |

## 실무 체크리스트

- [ ] 캠페인-광고그룹-키워드/소재 3단계 구조 설계
- [ ] 키워드 유형별(브랜드/경쟁/정보) 광고그룹 분리
- [ ] 네이버: **최적화 지수**(광고 연관지수·클릭 기대지수)로 품질 모니터링 (품질지수 2026.7 종료)
- [ ] 구글: 품질평가점수 3대 구성요소 점검
- [ ] 랜딩 페이지 = 광고 소재와 일관성 + 모바일 최적화
- [ ] 부정/제외 키워드 관리, 시간대별 세팅
- [ ] 전환 정의(Primary) 정확히 설정 (자동 입찰 전제)
- [ ] 지역 타겟팅 설정 확인 ("거주하거나 자주 방문하는 사용자" 검토)
- [ ] 확장 소재 월 1회 이상 승인/랜딩 연결 점검
- [ ] A/B 테스트 지속, 소재 피로도(빈도·CTR 하락) 관리

> 참고: 블로그·카페 등 유기 채널과 광고를 병행할 때는 경제적 이해관계 표시(공정위 심사지침)와 광고성 도배 방지에 주의하세요.
