# 검색 마케팅

사용자가 검색하는 순간 브랜드를 발견하게 만드는 **검색 마케팅** 카테고리입니다.
네이버 중심의 국내 검색 생태계에서 SEO, 키워드 광고, 블로그·카페 마케팅을
어떻게 운영하는지 실무 관점에서 다룹니다.

## 주제 클러스터

- [SEO 기초](/search/clusters/seo-foundations/) — 검색 엔진 노출의 기본 원리와 온페이지·기술적 SEO 기초를 다루는 클러스터.
- [검색 광고 (Paid Search)](/search/clusters/paid-search/) — 키워드 광고 입찰·소재·전환 최적화 등 유료 검색 광고 운영을 다루는 클러스터.

## 이 카테고리에서 다루는 주제

- 국내 SEO 기초: 온페이지·오프페이지·기술적 SEO
- 네이버 검색 알고리즘 (C-Rank, D.I.A.) 이해
- 키워드 광고: 파워링크/SA, 구글 애즈 입찰 전략
- 블로그·카페 마케팅 상위노출 전략
- AI 브리핑 시대의 검색 전략 전환
